# Devpost submission materials

- **`DEVPOST_DESCRIPTION.md`** — draft text for Devpost's project
  description fields (inspiration, what it does, how we built it,
  challenges, accomplishments, what we learned, what's next). Paste
  directly, or edit — every claim in it is something verified live, see
  `docs/IMPLEMENTATION_PLAN.md` §3.4 for the receipts.
- **`architecture-diagram.html`** — the architecture diagram deliverable.
  Open it directly in a browser (or re-publish it as a Claude Artifact) to
  view/screenshot for the Devpost image upload. Two figures: the
  end-to-end system architecture, and the multi-agent pipeline detail with
  each tool marked real vs. simulated.
- **`DEMO_SCRIPT.md`** — a ~4-minute shot list for the required demo
  video, timed against the live Cloud Run URL. Includes a cut list if
  you're running long.
