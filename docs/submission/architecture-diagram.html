The six Fortified Enterprise Fleet pillars

Design-to-build status, honestly — not aspirational. See docs/IMPLEMENTATION_PLAN.md §3.1 for the full detail behind each line.

Agent Registry
Static directory, 7 agents, their declared permissions — served live via /api/registry.
Agent Runtime
Real Runner/Sequential/ParallelAgent execution, deployed — still bound to one HTTP request's lifetime.
Memory Bank
Real Firestore when deployed, in-memory locally — auto-selected by Cloud Run's own K_SERVICE.
Agent Identity
Zero-Trust wired as a real beforeToolCallback on every tool-bearing agent — fail-closed by default.
Agent Gateway
One PolicyEngine.evaluateAction() call site for every spend/booking decision, no per-agent drift.
Model Armor
Real prompt-injection scanning, verified against a live attack payload — tool-poisoning/PII checks not yet built.
Agent Observability
Live TelemetryLog console plus real OTel GenAI spans exported to Cloud Trace.
